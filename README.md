# Orderflow 🤖
AI-powered WhatsApp ordering system for Nigerian food vendors and multi-vendor businesses.

## What it does
- Customers send "Hi" → bot replies with live menu
- Customer selects items → order confirmed automatically
- Owner sees clean dashboard — no manual chat management
- Supports multiple vendors and multiple countries (adjusts currency + tone)

## Tech Stack
- **Backend:** Node.js + Express (deployed on Render)
- **Database:** Supabase
- **AI Engine:** Claude AI (Anthropic)
- **WhatsApp:** Baileys library
- **Frontend:** HTML/CSS/JS (deployed on Netlify)
